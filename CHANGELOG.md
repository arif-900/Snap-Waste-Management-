# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-04

### Added
- Initial project release of the Smart Waste Management Platform.
- Frontend Citizen Portal with Mapbox geolocation support.
- FastAPI backend serving YOLO-based waste identification.
- Support for Google Gemini suggestions and tips generator.
- Supabase synchronization integration for live statistics.

### Security
- Added secure environment variable parsing configuration.
- Excluded raw credentials from public distribution lists.
